# Screening and model status

Screening is a rule-based research component, not a trained classifier. It uses versioned FTSE Yasaar public initial filters with provenance and explicit missing-evidence states. There are no learned screening weights, accuracy claim or official Yasaar certification.

The retained 2025-12-31 screen has no fully evidenced pass or portfolio-eligible stock. Business/product revenue and complete income/financial mappings remain limitations. This module must not supply invented pass labels for model training.

Teammate return/risk notebooks and modeling dataset remain separate and unchanged by this task. No prediction model was trained or re-evaluated. Read screening_methodology.md and evaluation_report.md for the screening scope; do not interpret this card as verification of another branch's trained artifacts.
