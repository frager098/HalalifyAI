# Phase 7 notebooks — candidate model comparison

This folder is an easy starting point. The actual Phase 7 notebooks remain one level above, in `notebooks/`. They were not moved because the project documents and Git history already use those paths.

Phase 7 compares the selected return and risk features with two model types. Its code is ready; reports will be created only after the notebooks are run with the verified Phase 6 data available locally.

Run these notebooks in this order:

1. `../phase7_handoff_and_runner_validation.ipynb`
2. `../phase7_return_logistic.ipynb`
3. `../phase7_return_hist_gradient_boosting.ipynb`
4. `../phase7_return_review.ipynb`
5. `../phase7_risk_logistic.ipynb`
6. `../phase7_risk_hist_gradient_boosting.ipynb`
7. `../phase7_risk_review.ipynb`
8. `../phase7_final_report.ipynb`

After the full sequence finishes, the results will be saved in `../../reports/model_evaluation/phase7_candidate_tuning_v1/`.

Read `../../docs/PHASE7_RUNBOOK.md` and `../README.md` before running them.
