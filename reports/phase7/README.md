# Phase 7 reports — model comparison

Phase 7 trains and compares the frozen Phase 6 candidates. This folder is a
simple guide; generated Phase 7 files remain in the location used by the code.

## Read these first

- `../../docs/PHASE7_RUNBOOK.md` — what to run and in which order.
- `../../configs/phase7_handoff_v1.json` — required Phase 6 inputs and their
  checksums.

## Generated Phase 7 evidence

After you run the eight Phase 7 notebooks, files will appear here:

`../model_evaluation/phase7_candidate_tuning_v1/`

It will contain:

- handoff validation and experiment contract;
- return Logistic Regression and HistGradientBoosting results;
- return decision report;
- risk Logistic Regression and HistGradientBoosting results;
- risk decision report; and
- the final Phase 7 summary.
